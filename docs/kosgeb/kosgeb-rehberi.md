# KOSGEB Destekleri

KOSGEB, KOBİ'lerin rekabet güçlerini artırmak ve ekonomik büyümeye katkılarını sağlamak amacıyla çeşitli destek programları sunar.

## Başvuru Süreci İş Akışı

```mermaid
graph TD
    A[KOSGEB Veritabanına Kayıt] --> B{KOBİ Beyannamesi Onaylı mı?}
    B -- Hayır --> C[Beyanname Doldur ve Onaya Sun]
    C --> B
    B -- Evet --> D[Uygun Destek Programını Seç]
    D --> E[Proje/İş Planı Hazırla]
    E --> F[KBS Üzerinden Başvuruyu İlet]
    F --> G{Kurul Değerlendirmesi}
    G -- Red --> H[Eksikleri Gider / İtiraz Et]
    G -- Onay --> I[Destek Süreci Başlar]
```
