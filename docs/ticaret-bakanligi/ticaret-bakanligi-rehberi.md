# Ticaret Bakanlığı Destekleri

Ticaret Bakanlığı, özellikle ihracat yapmak veya uluslararası pazarlara açılmak isteyen işletmelere yönelik teşvikler sağlar.

## İhracat Destekleri İş Akışı

```mermaid
graph LR
    A[DYS Sistemine Kayıt] --> B[Harcanan Tutarı Faturalandır]
    B --> C[Ödemeyi Banka Yoluyla Yap]
    C --> D[DYS Üzerinden Destek Başvurusu]
    D --> E{İnceleme Süreci}
    E -- Eksik Evrak --> F[Eksikliği Tamamla]
    F --> D
    E -- Onay --> G[Ödeme Emri (TCMB)]
    G --> H[Hesaba Aktarım]
```
