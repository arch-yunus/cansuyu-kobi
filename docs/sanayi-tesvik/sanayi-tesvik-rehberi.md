# Sanayi ve Teknoloji Bakanlığı & Yatırım Teşvikleri

Sanayi ve Teknoloji Bakanlığı, bölgesel kalkınmayı hızlandırmak ve teknolojik yatırımları artırmak için teşvikler verir.

## Yatırım Teşvik Belgesi Süreci

```mermaid
graph TD
    A[E-TUYS Sistemine Yetkilendirme] --> B[Yatırım Projesi Hazırlığı]
    B --> C[E-TUYS Üzerinden Başvuru]
    C --> D{Bakanlık İncelemesi}
    D -- Revizyon --> E[Projeyi Güncelle]
    E --> C
    D -- Onay --> F[Yatırım Teşvik Belgesi Düzenlenir]
    F --> G[Yatırıma Başla ve Faturaları İşle]
    G --> H[Yatırım Tamamlama Vizesi]
```

## Teşvik Türleri
- Bölgesel Yatırım Teşvik Mevzuatı
- Teknogirişim Sermayesi Desteği
- Teknoloji Geliştirme Bölgeleri (Teknoparklar)
